# My Portfolio 🚀

Welcome to my personal portfolio! This project showcases my skills, projects, and experience as a Frontend Developer.

Built with:  
- **Next.js** – React framework for fast, server-side rendered websites  
- **TypeScript** – Strongly typed JavaScript for better code quality  
- **Tailwind CSS** – Utility-first CSS framework for responsive designs  
- **Framer Motion** – Smooth animations for interactive UI  

## Features ✨
- Modern and responsive design  
- Interactive animations and transitions  
- Sections: About Me, Projects, Skills, Contact  
- Fully mobile-friendly
